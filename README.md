# CAPS DI Support

© 2026 Research and Development Africa (RADAF). All rights reserved. See [LICENSE](LICENSE).

CAPS DI is an assessment-informed pedagogical support platform for South African
Foundation Phase teachers. This repository contains only the public web app (the
screens). The lesson-plan engine, RADAF's pedagogical knowledge base and the
instructions used to generate plans run on a private server and are not published here.
